Genesis is a modular ECS Game Engine personal project made for learnign proposal.

Mainly followed TheCherno course series, mixed with personal research and experience in Game Development University Grade!
- Game Engine Series: https://www.youtube.com/playlist?list=PLlrATfBNZ98dC-V-N3m0Go4deliWHPFwT

Supported OS:
- Windows

Libraries and technologies used:
- VS 2026 and C++20.
- Spdlog: Loggin messages management. [https://github.com/gabime/spdlog]
- Premake: Project archives generator. [https://github.com/premake/premake-core]
- GLFW: Creates windows and OpenGL/Vulkan contexts, manages input. [https://github.com/glfw/glfw]
- Glad: Loads modern OpenGL functions dynamically. [https://glad.dav1d.de/]
- ImGui: Immediate mode graphical user interface for debugging tools and editor interfaces. [https://github.com/ocornut/imgui]
